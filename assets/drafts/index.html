Outcome drafts, by hand in the free Gemini app (Nano Banana 2). For each draft:
  1. Open a new chat in Gemini. Attach the card's reference images (click one to open it full size).
  2. Click copy prompt for that draft (v1, v2…), paste and send. Ask for fixes in the same chat if needed.
  3. Download it into assets/drafts/gemini/<level>/ and name it with copy name. PNG, JPG or WEBP.
  4. Click Reload. The draft appears; the gold card is the next one to do.
